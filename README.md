# sergiolearns-codigo

El código completo de los artículos de **[sergiolearns.com](https://sergiolearns.com)**: los programas resueltos y las soluciones de los ejercicios de Python, Java, C y MIPS, ordenados por lenguaje y tema, listos para copiar, ejecutar y romper.

Cada archivo empieza con un comentario que dice de qué artículo sale, así que siempre puedes volver a la explicación paso a paso.

## Qué hay dentro

130 programas de Python, 92 de Java, 95 de C, 40 de Linux (bash), 51 de MIPS y 68 simuladores y comprobaciones en Python (3 de redes, 20 de sistemas operativos y 45 de computadores), en 83 temas, y 4 simulacros de examen práctico (IC2 en C, FP2 en Python y Java, FP1 en Python e IC1 en MIPS). En [`proyectos/escritorio/`](proyectos/escritorio) está el código completo de cada versión de El cuarto de Sergio (el cuarto en 3D de la web). En [`herramientas/entorno/`](herramientas/entorno) está el editor del entorno de programación de los simulacros de FP2. En [`herramientas/mips/`](herramientas/mips) están los colores y el autocompletado de MIPS para Notepad++ (`notepad++/MIPS-colores.xml` y `notepad++/autoCompletion/MIPS.xml`) y el programa de ejemplo de las guías de QtSpim (`ejemplos/suma.s`), de IC1. En [`herramientas/mips/entorno/`](herramientas/mips/entorno) está el entorno MIPS de la web (editor + simulador con el núcleo de SPIM en WebAssembly, licencia BSD).

## Cómo ejecutarlos

```bash
# Python
python python/bucles/programas/01-programa-1-el-pin-de-la-caja.py

# Java: cada programa tiene su carpeta con todas sus clases
cd java/bucles/programas/AnalizadorTexto
javac *.java
java AnalizadorTexto

# C
gcc c/punteros/programas/01-*.c -o programa
./programa

# MIPS: ábrelo en QtSpim (Reinitialize and Load File) o en el entorno MIPS de la web
# mips/estructura-y-datos/programas/01-programa-1-el-mapa-de-memoria-del-inventario.s

# Linux (bash): sesiones de terminal; ejecútalas en una carpeta de pruebas, nunca como root
mkdir ~/prueba && cd ~/prueba
bash ~/sergiolearns-codigo/linux/permisos/programas/01-programa-1-montar-la-carpeta-del-grupo.sh
```

¿Es la primera vez? En la web tienes cómo [instalar Python en Windows](https://sergiolearns.com/instalar-python-en-windows/), [instalar Java](https://sergiolearns.com/instalar-java-en-windows/) y [compilar C con gcc en Fedora](https://sergiolearns.com/instalar-gedit-en-fedora-y-compilar-con-gcc/).

└── tema/
